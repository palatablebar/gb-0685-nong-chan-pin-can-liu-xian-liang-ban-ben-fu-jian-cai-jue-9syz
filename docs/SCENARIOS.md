12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001，判为PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL。最终24项目，12PASS、12FAIL，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。

## 补正裁决场景（M8）

同一复检报告00002先后收到两份补正：AM-2026-001 更正检出限（lod 0.001→0.002），AM-2026-002 更正采样日期（2026-08-01→2026-06-15）。第一份整版叠加后全链路通过，形成版本3并成为当前依据；第二份叠加后与原报告00001采样日不再一致，触发复检关联 REFERENCE 校验，整份驳回并留痕，当前依据保留版本3，批次仍可凭既有合格证据出证。若直接按到达先后拼字段，会得到采样日与LOD互相矛盾、无证据支撑的版本；若全部退回，则合格批次错过出证。补正链可在工作台“重新核对”按台账重放并比对运行指纹。
